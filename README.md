# لمسة المستقبل

موقع عربي كامل لخدمات الدهانات والجبس بورد والديكور والترميم والتجديد في الرياض وشمال الرياض. صفحات عامة تُعرض من الخادم، ولوحة إدارة على `/admin`، وقاعدة بيانات SQLite على قرص دائم.

## التشغيل

يتطلب Node.js 24 أو أحدث.

```sh
npm ci
cp .env.example .env
npm start
```

افتح `http://localhost:3000`. عدّل `SITE_URL` في بيئة الإنتاج إلى الرابط الفعلي ليُستخدم في الروابط الأساسية وخرائط الموقع. لا تضع أي أسرار في ملفات الواجهة أو GitHub.

## حساب الإدارة

في الإنتاج، إذا لم يُنشأ حساب مسؤول، يُولّد الخادم رابط إعداد عشوائيًا صالحًا لساعة واحدة ويعرضه في سجل الاستضافة باسم `ADMIN_SETUP_URL`. افتح الرابط الخاص واختر بريدك وكلمة مرورك. يُحفظ تجزئة الرمز فقط، ولا يعمل بعد إنشاء أول مسؤول. إعادة تشغيل الخادم تستبدل الرابط السابق. لا تنشر الرابط ولا تضعه في المستودع.

يمكن إنشاء المالك الأول بإعداد `ADMIN_EMAIL` و`ADMIN_PASSWORD` في متغيرات البيئة قبل أول تشغيل. يجب ألا تقل كلمة المرور عن 12 حرفًا. بعد إنشاء الحساب يمكن إزالة `ADMIN_PASSWORD` من متغيرات الاستضافة.

يمكن أيضًا استخدام الأمر:

```sh
npm run admin:create
```

الأمر يقرأ البريد وكلمة المرور من متغيرات البيئة فقط. لإعادة ضبط حساب موجود بشكل مقصود استخدم `npm run admin:create -- --reset`؛ تلغى جلساته السابقة.

تتضمن لوحة الإدارة:
- صور الواجهة: رفع، ترتيب بالسحب، تفعيل وإخفاء، عناوين وروابط ومدة العرض.
- الخدمات والمشاريع والمعرض وصور قبل وبعد.
- المقالات وصفحات الأحياء وSEO والعروض والتصنيفات والتقييمات.
- طلبات عروض الأسعار والرسائل وحالات المتابعة؛ صور العملاء لا تُعرض إلا للمسؤول.
- اسم النشاط وأرقام التواصل والشعار والأيقونة وألوان الموقع وصورة المشاركة والإحصائيات.
- حقول مباشرة للمحتوى الشائع، ومحرر JSON للبيانات الإضافية والنصوص المتقدمة.

## البيانات والصور

الصور الأولية إلهامية من Unsplash، ولا تُنسب إلى أعمال الشركة. المشاريع الأولية مصنفة بوضوح كتَصوّرات. لم تُختلق تقييمات أو إحصائيات أو عناوين شوارع أو مشاريع منفذة. الإحصائيات مخفية، وصور قبل وبعد والتقييمات تُضاف من لوحة الإدارة عند توفر بيانات موثقة.

كل المحتوى الأولي موجود في `src/content.mjs` ويُنسخ مرة واحدة فقط عند إنشاء قاعدة بيانات جديدة. التعديل بعد ذلك من لوحة الإدارة، ولا تُستبدل تغييرات المسؤول عند إعادة تشغيل الخادم. أضف بيانات الإحصائيات الصحيحة قبل تفعيلها.

يمكن رفع JPG/PNG/WebP/AVIF. تُفحص الصور فعليًا وتُعاد معالجتها إلى WebP؛ لا يكفي تغيير امتداد الملف. حد الصورة 5 ميجابايت؛ نموذج عرض السعر يسمح بست صور. لا ينتقل رفع الصور تلقائيًا إلى واتساب: حفظ النموذج ومشاركة تفاصيله عبر واتساب عمليتان واضحتان.

رقم النشاط: `+966501308295`. رابط واتساب يُبنى دون علامة +، مع الرسالة المطلوبة، ورابط الاتصال يستخدم `tel:`.

## النشر والتخزين الدائم

المشروع يتضمن Dockerfile وCompose. على الخادم:

```sh
docker compose up -d --build
```

يحفظ Compose البيانات والصور في volume باسم `site-data`. استخدم HTTPS أمام التطبيق في الإنتاج؛ cookies الإدارة تكون Secure في الإنتاج.

على Railway أو استضافة حاويات مشابهة:
1. انشر المستودع باستخدام Dockerfile.
2. اربط قرصًا دائمًا عند `/app/data`.
3. اضبط `DATABASE_PATH=/app/data/site.db` و`UPLOADS_DIR=/app/data/uploads`.
4. اضبط `NODE_ENV=production` و`TRUST_PROXY=1` فقط خلف طبقة proxy واحدة موثوقة، و`SITE_URL` للرابط المنشور.
5. فحص الصحة: `/healthz`. نسخة واحدة للتطبيق عند استخدام SQLite.
6. أنشئ حساب الإدارة، ثم استبدل الصور الإلهامية وصور المشاركة بصور النشاط.

لا تستخدم تخزين الحاوية المؤقت لطلبات العملاء. احتفظ بنسخ احتياطية من قاعدة البيانات والصور. قبل نسخ SQLite أثناء التشغيل استخدم أداة backup الخاصة بـSQLite، أو أوقف الخادم أثناء النسخ حتى تبقى ملفات WAL متسقة. النسخة الاحتياطية تشمل مجلد الصور أيضًا.

## الأمان

تجزئة كلمات المرور bcrypt، وجلسات محفوظة في قاعدة البيانات برموز عشوائية مجزأة، وملفات cookies من نوع HttpOnly/SameSite، وحماية CSRF والتحقق من origin، وصلاحيات الإدارة، وتحديد معدل تسجيل الدخول والنماذج. استعلامات SQL تستخدم معاملات، ومحتوى EJS يُهرب لمنع HTML غير الموثوق. لا توجد كلمة مرور افتراضية.

## الاختبارات

```sh
npm run check
npm test
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

GitHub Actions يشغّل فحص المصدر وEJS، واختبارات الصفحات والحفظ والأمان، واختبارات متصفح Chromium وWebKit على إعدادات سطح المكتب وiPhone وiPad وAndroid. تقارير المتصفح وصور الفحص تُحفظ كملفات مرفقة في تشغيل Actions؛ هذه محاكاة متصفحات وأبعاد وليست اختبارًا على أجهزة فعلية.

## SEO والصفحات

14 صفحة خدمة، وصفحات مشاريع ومقالات وتسعة أحياء بمحتوى مختلف. H1 واحد لكل صفحة، Meta وCanonical وOpen Graph وTwitter Cards، وLocalBusiness وService وBreadcrumb وArticle schema، إضافة إلى `/sitemap.xml` و`/robots.txt`. لا يتضمن ذلك ادعاء أو ضمان ترتيب معين في Google.

الواجهة تحترم RTL وتقليل الحركة، وتحتوي على سلايدر صور وتصفية للمعرض وLightbox ومقارنة صور قبل وبعد عند إضافتها. نماذج الموقع تعمل من الخادم، والاتصال وواتساب يعملان كروابط أصلية.

## البنية

`src/`: الخادم وقاعدة البيانات والأمان وإدارة المحتوى الأولي.  
`views/`: قوالب EJS ومكونات عامة وإدارية قابلة لإعادة الاستخدام.  
`public/`: CSS وJavaScript خفيف للواجهة ولوحة الإدارة.  
`database/schema.sql`: تعريف الجداول.  
`tests/`: اختبارات API وتجربة المتصفح.  
`scripts/`: فحص المصدر وإنشاء حساب الإدارة.
